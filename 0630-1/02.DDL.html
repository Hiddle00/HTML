SQL(Structured Queay language, 구조적 질의어) DBMS에서 사용하는 명령어 Create,Alter,Drop,Truncate 1.DDL(Data Definition Language, 데이터 정의어) 데이터베이스 내에서 개체(Entity, 데이터베이스, 테이블)들을 생성하거나, 수정하거나, 삭제하는 명령어들의 집합 1.CREATE 새로운 개체를 생성하는 명령어 1-1.데이터베이스 개체 생성 create database {if not exists} [데이터베이스이름] {incording} --실제 create database ezen; ezen이라는 이름의 데이터베이스 생성 1-2. 테이블 개체 생성 create table {if not exists} [테이블이름]( [컬럼이름1] [데이터타입] {제약조건}, [컬럼이름2] [데이터타입] {제약조건}, ...... [컬럼이름n] [데이터타입] {제약조건} ){테이블 옵션}; (할당된 공간을 모두 쓰지않아도 할당되어 있기 ) var(valuable)char - 사용하지 않은 공간은 자동으로 반환함. 길이제한이 있음. text --문자열 타입 tinyint(db의 true,false) 자주 쓰이는 데이터 타입 varchar: 문자열. 컬럼에 들어가는 데이터가 문자열일때 사용한다. 저장공간을 절약하기 좋다. ex) varchar(20)은 최대 20byte의 문자열을 저장할 수 있다. 이 때, 저장하는 데이터가 10byte라면 나머지 공간 10byte를 쓰지 않고 공간을 축소한다. text: 문자열. 컬럼에 들어가는 데이터가 문자열이고, 최대 길이(크기)를 알 수 없을때 사용한다. int: 컬럼에 들어가는 데이터가 정수일 때 사용한다.(2^64를 넘을 수 있음) double: 실수. 컬럼에 들어가는 데이터가 실수일 때 사용한다. timestamp / datetime: 날짜. 컬럼에 들어가는 데이터가 날짜일때 사용한다.
