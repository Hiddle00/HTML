3. 범위 조건 특정 범위 내의 데이터를 조회 할 때 사용한다. #문법 where [컬럼이름] between [값1] and [값2]; 3-1. age가 20과 30사이인 행만 조회 select *from user where age between 20 and 30; 3-2. age가 30과 20사이인 행만 조회 select *from user where age between 30 and 20; 4-2. id가 hong,jeon에 포함되는 값을 가지고 있는 행만 조회한다. select *from user where id in ('hong', 'jeon'); 4-3. pw가 1234, 54321에 포함되는 값을 가지고 있는 행만 조회한다. select *from user where pw in ('1234', '54321'); 4-4. height가 180.7,168.2에 포함되는 값을 가지고 있는 행만 조회 select *from user where height in (180.7, 168.2); 5. null 조건 null값을 가지는 데이터를 조회할 때 사용한다. null의 문제 1. 비교연산(=,!=,>)에 필터링 되지 않음. select *from user where age = null; select *from user where age = NULL; 위 쿼리는 필터링이 불가 5-1. age컬럼의 값이 null인 행만 조회 select *from user where age is null; 5-2. height 컬럼의 값이 null인 행만 조회 select *from user where height is null; 5-3. id 컬럼의 값이 null인 행만 조회 select *from user where id is null; 5-4. age컬럼의 값이 null이 아닌 행만 조회 select *from user where age is not null; 5-5. id컬럼의 값이 null이 아닌 행만 조회 select *from user where id is not null; 5-6. id컬럼의 값이 null이 아니고 hong인 행만 조회 select *from user where id is not null and id = 'hong'; 6. 패턴 일치 조건 특정 패턴과 일치하는 데이터를 조회한다. #문법 where [컬럼이름] like '{%}'[값]'{%}'; 6-1. id컬럼의 값이 h인 행만 조회 select *from user where id like 'h'; 6-2. id컬럼의 값이 h로 시작하는 행만 조회 select *from user where id like 'h%'; 6-3. id컬럼의 값이 g로 끝나는 행만 조회 select *from user where id like '%g'; 6-4. id컬럼의 값이 e로 시작하는 행만 조회 select *from user where id like 'e%'; 6-5. id컬럼의 값에 e가 포함되는 행만 조회 select *from user where id like '%e%'; 6-6. name컬럼의 값이 홍으로 시작하는 행만 조회 select *from user where name like '홍%'; 6-7. name컬럼의 값에 ㄱ이 포함되는 행만 조회 select *from user where name like '%ㄱ%'; 7. 행 수 제한 조회할 데이터의 수를 강제로 제한한다. #문법 limit {시작(행)번호,} [개수] 7-1. user테이블에서 하나의 데이터만 조회 select *from user limit 1; 7-2. user테이블에서 두개의 데이터만 조회 select *from user limit 2; 7-3. user테이블에서 10개의 데이터만 조회 select *from user limit 10; 7-4. user테이블에서 첫번째 행부터 한개의 데이터만 조회 select *from user limit 1, 1; 7-5. user테이블에서 0번째 행부터 한개의 데이터만 조회 select *from user limit 0, 1; 7-6. user테이블에서 2번째 행부터 두개의 데이터만 조회 select *from user limit 2, 2; 8. 행 수 제한2 #문법 limit [개수] offset [시작인덱스];
