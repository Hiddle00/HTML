기능 정의 - 어느 데이터를 작성하고 저장 할 것인지 이후 컬럼의 정의, 어떤 값을 입력할 것인지 테이블 > 컬럼 논리설계 화면보면서 어떤식으로 추가로 표시되지 않지만 필요한컬럼 논리설계 ( 게시판 글쓰기 글보기 글수정 글삭제 회원 > 아이디,비밀번호,닉네임,가입일 게시글 > 제목,본문,작성자,작성일,글번호 댓글 > 본문,작성자,작성일,댓글번호 ) 테이블 목록 테이블 컬럼 목록(컬럼이름,타입,제약조건) ERD > Entity Relationship diagram (개체 관계 도표) Entity - 개념적인 구상도 필드 > 테이블 - create table로 작성된 물리적인 저장소. 비식별관계 : 빌려온 관계지만 PK로 사용하지 않을 경우 식별관계 : PK로 사용할 경우 key를 빌려주는 entity가 부모가 되고 받는 entity가 자식이 된다. Relationship > Foreign key DDL 생성 회원 테이블 create table user( id varchar(255) primary key, pw varchar(255) not null, nick varchar(255) not null, create_date timestamp default now(), unique key(nick) ); 게시글 테이블 create table board( bno int primary key auto_increment, author varchar(255), title varchar(255) not null, content text not null, create_date timestamp default now(), foreign key(author) references user(id) ); 댓글 테이블 create table reply( rno int primary key auto_increment, rauth varchar(255), bno int, rcon varchar(255) not null, create_date timestamp default now(), foreign key(rauth) references user(id), foreign key(rno) references board(bno) );
